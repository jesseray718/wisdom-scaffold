# Roadmap

## Current Status

Wisdom Scaffold is an offline-first collection of reusable operational wisdom,
decision tools, and lightweight computational artifacts.

## Next 3–6 Months

1. Keep the wisdom corpus, ledgers, and computational flow reproducible on
   constrained hardware.
2. Improve contributor onboarding, issue intake, and project governance.
3. Maintain the cathedral-status audit and publish reusable documentation
   uplift materials for original OpenRoot repositories.
4. Record major project decisions using the
   [Three Ledgers framework](/home/runner/work/wisdom-scaffold/wisdom-scaffold/THREE_LEDGERS_DECISION_FRAMEWORK.md).

## Decisions Needed

- Prioritize additions that improve useful capability per unit of human effort.
- Review proposed licenses and governance changes with maintainers before
  adoption.
- Prefer offline-capable, inspectable artifacts over dependencies that reduce
  resilience.

## Vision Alignment

Progress is measured in real-world capability, sustainable operating cost, and
the documented reasoning that reconciles those two ledgers.
